# Export omissions

This snapshot excludes repository history, agent instructions and work logs,
private operational documents, device profiles, deployment and signing scripts,
customer artwork, packaged binaries and device E2E tests. Generic generated PNGs
replace the artwork; their appearance and nine-patch behavior require device review.
The original private history is not made safe by this snapshot. Review publication
rights, dependencies, privacy, configuration, and actual Roku behavior independently.
